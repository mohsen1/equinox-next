# Implementation plan

## Current phase

Phase 5 — local hardening and future-contract proof.

Acceptance statement: a clean checkout builds the complete Compose stack, completes both
CAD algorithms, preserves evidence through restarts, and passes contract, boundary,
integration, browser, and accessibility checks without a cloud credential.

## Completed evidence

- `scripts/preflight` passes on Apple Silicon with Docker 29.4, Compose 5.1, and Claude
  Code 2.1.220.
- The reviewer CLI advertises the exact `Fable 5` model and `high` effort.
- The canonical source specification is copied to `docs/equinox-next.md` with external
  source provenance.
- Product facts and the initial reuse decision are recorded.
- Version-one JSON contracts validate states, cursors, checkpoints, batches, iteration
  inputs, verification plans, proof bundles, judge results, metrics, rewards, and
  operation envelopes.
- PostgreSQL separates scientific and operational authority by schema and role; MinIO
  stores immutable SHA-256-addressed artifact bytes.
- The local mock agent completes a four-tree independent baseline and a true shared-prefix
  four-sibling branch run.
- The branch fixture includes recovered infrastructure/provider retries, an accepted
  negative geometry outcome, abstention without a judge-derived zero, and a blinded group
  judgment.
- Operation inputs, digests, versions, and fencing data support idempotent replay. An
  orchestrator restart after accepted transitions resumes the same collection and commits
  one iteration.
- The Operate dashboard exposes the real run, iteration, trajectory, verification,
  evidence, judge, reward, failure, provenance, and resource APIs.

## Next slice

Run the final clean-volume acceptance, browser evidence capture, Impeccable detector and

## Blockers and decision deadlines

No current blocker.

- Platform owner — replace logical session directories with hardened per-session
  containers before any untrusted policy code is introduced. Preserve the no-host-socket
  boundary or use a separately authenticated rootless control service.
- CAD research owner — integrate and calibrate a strong multimodal judge only when a
  human-scored CAD validation set, thresholds, and budget approval exist. Keep the local
  profile mock-only.
- CAD environment owner — replace the deterministic geometry fixture with a pinned CAD
  kernel and task bundle before measuring reconstruction quality. The current fixture
  proves lineage and failure semantics, not geometric generalization.
