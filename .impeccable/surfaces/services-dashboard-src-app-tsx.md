Scope: the Equinox Next web dashboard, especially run, rollout-tree, and verification
inspection routes. Mode: Operate.

Audience: RL researchers and research operators. Job: decide whether collected evidence
is valid and trace one committed policy update back to its exact lineage. Primary actions:
launch, select, inspect, cancel, reproduce, and rejudge. Proof is persisted API data:
states, attempts, renders, deterministic reports, model assessments, named rewards, and
immutable manifests.

Direction: The Verification Drafting Table. Use a compact rail and a shared-prefix
trajectory workspace whose true four-lane fan-out sits above synchronized
reference/source/candidate/sibling evidence. A right inspector shows the selected
verification DAG node and keeps deterministic facts separate from model assessment.

Memorable moment: selecting one sibling synchronizes its path, render, proof,
verification node, and reward lineage without losing the shared prefix.

Constraints: flat/no shadows, one product accent, automatic light/dark, WCAG 2.2 AA,
keyboard outline equivalents, URL-addressable selection, and no hidden evidence payloads.
At laptop widths, the inspector stacks below the graph without hiding the outline.
